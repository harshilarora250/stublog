# StuBlog
Welcome to the StuBlog - The Stupid Blog! 25% of all profits are donated to non-profit organizations like [HackClub](https://hackclub.com) & [FirstCommit](https://firstcommit.xyz)

## Forking
Here's how you can easily fork StuBlog and customise it to make it your own!
```
git clone https://github.com/harshilarora250/stublog
cd stublog
```
Yes, it's that easy. Then you can open the folder in your perffered web browser and start bloggin'!

## How it works
StuBlog is easy to use and recreate. To create blog pages, as an external writer, you can create a [pull request] in the repository and once approved, your post will be live! To view posts, you can simply click on their icon on the home page, and you can check it out!
